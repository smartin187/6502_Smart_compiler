# string library

This library is for string and character manipulation.

## Sub modules

### `convert.sma`

This module is for convertion from ASCII code of a number from a simple value to the number.

#### `int_to_char: .int`

This function return the ASCII character of the integer passed as argument.

#### `char_to_int: .char`

This function return the integer value of the ASCII character representation passed as argument.
